# Mando TV

Mando a distancia por infrarrojos para Android, sin anuncios. Infrarrojos: Samsung, LG, Sony, Philips y Panasonic. Smart TV por wifi: Samsung, LG, Sony Bravia y Roku. Stick/caja Android por Bluetooth (el móvil hace de mando).

La APK se descarga desde **Releases → Mando TV (última versión) → MandoTV.apk**.
